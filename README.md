# sunat-api

Aplicación de automatización de tareas tributarias con SUNAT (Perú): declaraciones mensuales, emisión de comprobantes y revisión de impuestos por pagar.

Página publicada: https://dc0512.github.io/sunat-api/

## Bot del Buzón Electrónico SOL

Lee las alertas de SUNAT del correo y descarga el contenido de los mensajes del buzón SOL. Ver [docs/bot-buzon.md](docs/bot-buzon.md).
